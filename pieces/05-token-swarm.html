Token swarm

Every token of an AI coding session is a particle: it runs hot while it flies untrusted, then cools to ice as it settles into code, a model, a shield, a lock and a verified mark.

  • Shapes rasterised offscreen, sampled by luminance into 24,576 seeded targets
  • Morph and curl-noise flow run per particle in a hand-written WebGL2 vertex shader
  • Point sprites stretched into soft capsules along their motion, coloured by speed
  • Trails from ghost passes, so each frame stays a pure function of t
  • Your pointer is a probe that pushes tokens aside and heats them up
