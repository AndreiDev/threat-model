Secure pipeline

An AI agent's changes ride a conveyor through a policy gate: clean ones cool to ice and ship signed, hot ones are diverted into quarantine.

  • Hand-rolled isometric engine: true 2:1 dimetric projection, extruded prisms, cylinders and an arch
  • Painter's algorithm with a topological depth sort that re-runs only when moving parts change
  • Retained SVG: every element is created once, then its attributes are set per frame from t alone
  • Code, labels and emblems skewed onto iso faces with SVG matrix transforms
  • Seeded token schedule: about one change in five heats up at the gate and diverts
