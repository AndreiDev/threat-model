Unsafe eval

eval(userInput) runs whatever a user sends as code. It shatters into hot glass and cools back together as JSON.parse(userInput), which only reads that input as data. Then the sink creeps back as new Function.

  • Three.js WebGPURenderer and TSL, compiled to WGSL (GLSL on the WebGL 2 fallback)
  • Glass shards moved by one TSL positionNode, a pure function of time
  • Three TextGeometry lines resampled to one triangle count and paired by position
  • MeshPhysicalNodeMaterial glass on a PMREM room, emissive from each shard's temperature
  • RenderPipeline post: bokeh depth of field on the code plane, then bloom
