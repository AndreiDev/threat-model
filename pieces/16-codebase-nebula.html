Codebase nebula

A 40-file repository drawn as a nebula of Gaussian splats. readSession() hands a cookie to node-serialize, which runs functions hidden in its input (CVE-2017-5941), so the file flares, its heat runs along the import graph to every dependant, and the fix cools it all down.

  • Spark 2.3.1 procedural splats: about 140,000 Gaussians pushed into one SplatMesh with pushSplat, seeded with mulberry32
  • Every source line is rasterised by Spark's textSplats(), then re-packed with its syntax class, line and column
  • One GLSL dyno objectModifier moves and recolours every splat from a time uniform: heat waves by graph distance, code condensing out of haze as the camera nears, the patch re-forming
  • Depth of field from Spark's aperture, UnrealBloomPass on the white-hot splats, and a seek hook that waits for Spark's sort worker
  • Drag to orbit; the camera returns to its flight path
