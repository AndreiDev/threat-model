Dark repo

A repository at night, drawn as a floor plan. The only light comes from code an agent is typing, until a reviewer's torch finds the SQL injection waiting in a back room.

  • 2D global illumination with radiance cascades in raw WebGL2: five cascade levels, probes spaced 2 to 32 px, 16 to 4,096 ray directions, merged top-down with bilinear probe interpolation
  • A jump flood pass rebuilds the distance field every frame, and every ray interval is sphere-traced through it
  • Bilinear fix on the near cascades: each ray aims at the four upper probes it merges with, so intervals meet without ringing
  • Typed code glyphs from a Martian Mono atlas are the light sources; the torch is a directional emitter
  • Move the pointer to carry your own torch; the scripted review comes back after 10 s idle
