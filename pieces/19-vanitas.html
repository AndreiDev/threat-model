Memento expirare

A Dutch vanitas still life painted stroke by stroke by a Python script, with no image models. Every object is something in security that expires.

  • Scene built in numpy: lathe solids, a curled page, SDF heightfields, a leaded window reflected in glass and brass
  • Hertzmann layered painting, from a 64 px brush to a 0.8 px liner, strokes traced along the structure tensor
  • Bristle-textured strokes with per-channel Kubelka–Munk wet mixing and an impasto height map lit for relief
  • Umber glaze, linen weave, craquelure and a lightly yellowed varnish
  • One seeded command renders the PNG and the timelapse: python3 tools/paint_vanitas.py

The AKIA access key prefix is documented in AWS IAM identifiers.
